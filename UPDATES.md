# How to update Nabeng Invoice

1. Open the project in VS Code.
2. Edit the appropriate file under `src/`.
3. Run `npm install` once on a machine with internet access.
4. Run `npm run dev` while developing.
5. Test sign-in, dashboard, customers, invoice creation, PDF, payments, recurring invoices, expenses and reports.
6. Run `npm run build` for production.
7. Deploy the project to Vercel/GitHub. Vercel will run the build automatically if connected to the repository.

Do not edit generated files under `dist/assets/`. They are recreated by Vite on every build.
